# 数据看板统计面板重构计划

## 1. 目标与概述
根据您的要求，我们将重新设计 `Dashboard.tsx` 页面顶部的数据统计面板：
- 移除与“库存”相关的两个统计面板（“库存总价值”和“库存余量”）。
- 将“今日利润”和“本月利润”升级为两个更大的重点面板（左右平分两列布局）。
- 在这两个利润面板中，额外增加显示“今天售出多少个商品”和“本月售出多少个商品”的数据。

## 2. 涉及修改的文件
- `src/pages/Dashboard.tsx`

## 3. 具体修改步骤

### 3.1 修改数据结构 (`DashboardData` 接口)
- **移除**：`inventoryValue` 和 `totalTickets` 字段。
- **新增**：`todaySoldQuantity` (今日售出数量) 和 `monthSoldQuantity` (本月售出数量) 字段。

### 3.2 调整数据拉取与计算逻辑 (`fetchDashboardData` 函数)
- **清理无用逻辑**：移除商品遍历时对全局库存数量 (`totalQty`) 和总价值 (`invValue`) 的累加。
- **完善销售数据拉取**：将抓取当月销售数据的 SQL 从 `.select('profit, sold_at')` 改为 `.select('profit, sold_at, quantity')`。
- **累加售出数量**：在遍历 `sales` 数据时，同时累加当月总售出数量和今日总售出数量（按 `quantity` 字段进行累加，以兼容历史多数量的单据记录）。
- **更新 `setData`**：将新计算出的四个字段存入组件状态。

### 3.3 重构 UI 渲染部分
- **删除旧组件**：移除原有的 `statCards` 数组及其对应的四列 `grid` 映射渲染逻辑。
- **构建新面板**：
  - 使用 `<div className="grid grid-cols-1 sm:grid-cols-2 gap-4 sm:gap-6">` 作为新的容器，确保在大屏上左右平分，在手机上上下排列。
  - **今日利润面板**：采用绿/青色渐变主题，突出显示大号字体格式的今日利润金额，并在下方用精致的标签（如：`px-3 py-1 bg-emerald-50 text-emerald-600 rounded-full`）显示“今天售出 X 个商品”。
  - **本月利润面板**：采用蓝/靛色渐变主题，突出显示本月利润金额，同样在下方增加标签显示“本月售出 X 个商品”。

## 4. 验证方式
1. 刷新看板页面，确认只有“今日利润”和“本月利润”两个大卡片。
2. 确认卡片内部正确显示了对应的售出商品数量。
3. 新增一笔售卖测试，验证“今日利润”和“售出商品数量”是否能实时且正确地增加。
